# Gogo Mobile Pet Grooming

This is a lightweight, responsive website for Gogo. Open index.html to preview it, or publish the repository root using GitHub Pages.

## Booking
The phone number is 760-889-5431. Call links use tel: and text links use sms:. Text buttons open a customer's messaging app with an editable message. They do not automatically send a message or confirm an appointment. No booking data is stored by this site.

## Business details
Services are presented as a starting menu. Review them against your actual offerings. Prices, operating hours, specific service cities, staff credentials, and customer testimonials have not been invented. Customers are directed to text their pet's details and ZIP code for confirmation.

## Editing
The page, styles, and small menu/text-link script are in index.html. Search for 17608895431 and 760-889-5431 when updating the phone number. The services and FAQ sections are marked with readable headings.

## Domain
The first launch uses GitHub Pages. No CNAME is configured for gogo.com. Connect a custom domain only after confirming ownership and configuring its DNS.
